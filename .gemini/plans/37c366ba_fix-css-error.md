# Plan: Tailwind v4 Alignment & CSS Error Fix

## Objective
Diagnose and permanently fix the `compileCSS` Vite error by strictly aligning the project with **Tailwind CSS v4** architecture, completely removing legacy v3 configuration paradigms.

## Scope & Analysis
1. **The Root Cause:** The project is running `tailwindcss@4.x.x` (verified via `package.json`). However, my previous UI overhaul attempted to configure the theme using a legacy `tailwind.config.js` file and mixed CamelCase class names (`app-primaryHover`) in `@apply` directives inside `App.css`. Tailwind v4 entirely drops `tailwind.config.js` in favor of configuring the theme via CSS variables and the `@theme` directive in the main CSS file. The engine crashed because it couldn't resolve the custom classes I injected into `@apply`.

2. **Phase 1: Tailwind v4 Native Configuration (`index.css`)**
   I will delete the legacy `tailwind.config.js`. I will update `client/src/index.css` to use Tailwind v4's native `@theme` block.
   ```css
   @import "tailwindcss";

   @theme {
     --color-app-bg: #0f172a;
     --color-app-surface: #1e293b;
     --color-app-primary: #7c3aed;
     --color-app-primary-hover: #6d28d9;
     --color-app-success: #34d399;
     --color-app-error: #f43f5e;
     --color-app-text-main: #f8fafc;
     --color-app-text-muted: #94a3b8;

     --shadow-arcade: 0 4px 0 0 rgba(0, 0, 0, 0.5);

     --animate-wiggle: wiggle 1s ease-in-out infinite;
     --animate-pop: pop 0.25s ease-out forwards;
     --animate-bounce-slow: bounce-slow 3s infinite ease-in-out;

     @keyframes wiggle {
       0%, 100% { transform: rotate(-3deg); }
       50% { transform: rotate(3deg); }
     }
     @keyframes pop {
       0% { transform: scale(0.95); }
       40% { transform: scale(1.02); }
       100% { transform: scale(1); }
     }
     @keyframes bounce-slow {
       0%, 100% { transform: translateY(0); }
       50% { transform: translateY(-8px); }
     }
   }
   ```

3. **Phase 2: CSS Refactoring (`App.css`)**
   * Remove the duplicate `@import "tailwindcss";` from `App.css`.
   * Update all `@apply` directives to strictly use the new kebab-case v4 variables generated by the `@theme` block (e.g., `text-app-textMain` becomes `text-app-text-main`, `bg-app-primaryHover` becomes `bg-app-primary-hover`).

4. **Phase 3: React Component Kebab-Case Synchronization**
   * Globally find and replace any instance of camelCase custom Tailwind classes in the `.jsx` files to match the new v4 kebab-case standard.
     * `text-app-textMain` -> `text-app-text-main`
     * `text-app-textMuted` -> `text-app-text-muted`
     * `bg-app-primaryHover` -> `bg-app-primary-hover`
   * Update `App.jsx`, `AdventureMap.jsx`, `LetterPicker.jsx`, `SoundMatcher.jsx`, and `MasteryStrip.jsx`.

## Verification
* Run `npm run build` in the `client` directory to confirm the CSS compilation succeeds without errors.
* Run `npm test` to ensure component stability.
* Update `CHANGELOG.md` to reflect the permanent transition to Tailwind v4 configuration standards.
