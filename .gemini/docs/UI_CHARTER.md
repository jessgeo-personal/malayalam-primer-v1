# UI CHARTER: Project "Malayalam Prime" Soft Premium System

## 1. Design & Aesthetic Philosophy
* **Core Reference Material:** Strictly emulate the color blocking, card stack layouts, and hyper-rounded button structures visible in "Ui Style Sheet.jfif".
* **Design Language:** "Neo-Bento Minimalism" — characterized by soft pastel canvases, heavy corner curves, deep text contrast, and flat, clean layout partitions.
* **Target Usability:** High tap-target spacing for 8-year-olds on tablets, with a clean, professional finish that remains mature enough for a 16-year-old.

## 3. Typography Hierarchy & Weight Distribution
To guarantee readability and immediate engagement, all interface text must strictly follow this typographical weight matrix:
* **Primary Numbers & Metrics (e.g., 78%, 44, 12):** Must use font-extrabold text-prime-darkText text-7xl tracking-tight. Numbers drive confidence; they must pop first.
* **Section Headers & Titles (e.g., "Learning progress", "Leaderboard"):** Must use font-bold text-prime-darkText text-2xl lg:text-3xl tracking-normal.
* **Action Labels inside Dark Pills:** Must use font-semibold text-white text-sm tracking-wide.
* **Sub-labels & Secondary details (e.g., "Average progress"):** Must use font-medium text-slate-500 text-sm.

## 4. UI Component Design Blueprints
### 4.1 The Action Dark Pill (Primary Button)
As seen in "Ui Style Sheet.jfif" (e.g., the "Request Demo" and subject tag buttons), primary inputs are dark, high-contrast capsules.
* **Tailwind Class Footprint:** bg-prime-actionDark text-white font-semibold px-5 py-2.5 rounded-pill shadow-sm hover:scale-[1.02] transition-transform flex items-center gap-2 max-w-max

### 4.2 Bento Grid Cards & Flashcards
Cards do not use harsh borders or dark drop shadows. They use deep background color blocks or clean borders with crisp interior layout tracking.

* **Type A (The Pastel Feature Block):** A solid background color field containing high-contrast white text cards inside.
    * Class footprint: bg-prime-coralPink text-white p-6 rounded-bento shadow-sm flex flex-col justify-between

* **Type B (The Main Surface Container):** Lighter baseline structures that separate information naturally.
    * Class footprint: bg-white border border-orange-100/50 p-6 rounded-bento flex flex-col relative overflow-hidden

### 4.3 The Progression Chart & Meter Line
For learning charts (as illustrated in the central panel of "Ui Style Sheet.jfif"), avoid technical grid lines. Use fluid curves with bold tracking anchors.
* **Line Style:** Thin, smooth curves (stroke-prime-coralPink with a width of 3px).
* **Anchors:** Main metric positions pinned using white circular pill nodes with dark percentage readouts (bg-prime-actionDark text-white px-2 py-1 rounded-md text-xs font-bold).

## 5. Homepage & Dashboard Layout Architecture
The homepage structure generated by the CLI must implement the layout balance found in the source sheet:
1. * **The Hero Header Slot:** A warm split canvas. Top section uses a vibrant theme color background (e.g., bg-prime-coralPink or bg-prime-tealGreen) hosting the child's welcome header ("Hi, Jacob"), profile avatar node, and a dark action pill tracking current progress level.
2. * **The Learning Plan Bento Grid:** Immediate access to quick stat boxes arranged in clean column spans:
    * Total Lessons Unlocked Card
    * Completed Items Card
    * Active Cycle Progress Tracker Card (Featuring the giant numeric layout)
3. * **The Active Module Course Deck:** Stacked horizontal cards representing current grammatical cycles (Cycle 1 through Cycle 4), utilizing alternating background accents (bg-prime-periwinkle, bg-prime-mangoOrange, bg-prime-tealGreen) with crisp white interior action buttons.
4. * **The Global Navigation Dock:** A highly distinct, floating dark menu capsule at the very bottom of the screen (bg-prime-actionDark mx-auto my-4 max-w-md rounded-pill px-6 py-3 flex justify-between items-center text-white) housing primary touch icons for the game.
